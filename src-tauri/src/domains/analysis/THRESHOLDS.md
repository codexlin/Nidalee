# 对局评分阈值

当前 `thresholds.rs` 只维护 KDA 到等级的映射，作为兼容前端展示的稳定业务规则：

| KDA | 等级 |
| --- | --- |
| `>= 8.0` | `S+` |
| `>= 6.0` | `S` |
| `>= 4.0` | `A` |
| `>= 2.5` | `B` |
| `>= 1.5` | `C` |
| `< 1.5` | `D` |

其余分析判断由 evidence 与 pipeline 根据队列、位置和数据质量处理，不应在此文件
重新建立另一套阈值系统。修改等级边界时必须同步更新 `thresholds.rs` 的单元测试。

## 系统概述

符文自动配置系统是 Nidalee 的核心功能之一，提供以下能力：

- ✅ **自动应用符文**：选人阶段自动配置最佳符文
- ✅ **双模式设计**：简单模式（零配置）+ 复杂模式（精细控制）
- ✅ **智能匹配**：7级优先级算法，精准匹配
- ✅ **可视化编辑**：完整的符文选择器，带图标和说明
- ✅ **一键导入**：从 OP.GG 或游戏客户端快速导入
- ✅ **数据安全**：本地持久化，数据永不丢失

## 快速开始

### 方式 1：使用 OP.GG 自动符文（新手推荐）

1. 打开 Nidalee
2. 进入"**设置 > 符文配置**"
3. 在"**简单模式**"中：
   - ☑️ **启用自动符文配置**
   - 选择策略："**智能模式**"（推荐）或"**仅 OP.GG**"
   - 选择段位："**钻石以上**"（推荐）
4. 进入游戏选人阶段
5. 选择英雄
6. ✨ **系统自动应用符文！**

### 方式 2：创建自定义配置（进阶用户）

1. 进入"**设置 > 符文配置 > 复杂模式**"
2. 点击"**新增配置**"
3. 填写基础信息：
   - **配置名称**：例如"劫-中路-电刑"
   - **作用域**：选择"英雄+位置专属"
   - **英雄**：输入"劫"搜索并选择
   - **位置**：选择"中路"
   - ☑️ **设为默认**
4. 选择符文（三种方式）：
   - **方式 A**：点击"**从 OP.GG 导入**"（最快）
   - **方式 B**：手动选择（可视化界面）
   - **方式 C**：点击"**从客户端导入**"（保存当前符文）
5. 点击"**创建**"保存
6. ✨ **下次选劫+中路时自动应用此配置！**

## 功能详解

### 1. 简单模式（自动应用）

#### 功能说明
无需任何配置，一键启用自动符文应用。

#### 配置选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| **启用自动符文配置** | 总开关 | 关闭 |
| **优先级策略** | 智能/仅OP.GG/仅自定义 | 智能 |
| **OP.GG 段位参考** | 推荐符文的段位 | 钻石以上 |
| **显示应用成功提示** | Toast 通知 | 开启 |

#### 策略说明

- **智能模式**（推荐）：优先使用自定义配置，如果没有则回退到 OP.GG
- **仅 OP.GG**：总是使用 OP.GG 推荐符文
- **仅自定义**：只使用用户自定义配置，如果没有则不应用

### 2. 复杂模式（自定义配置）

#### 配置管理

- **新增配置**：创建新的符文配置
- **编辑配置**：修改现有配置
- **删除配置**：移除不需要的配置
- **设为默认**：标记为该英雄+位置的默认配置
- **搜索**：输入英雄名称搜索配置
- **筛选**：按位置筛选配置
- **导出**：保存所有配置为 JSON 文件

#### 作用域类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **英雄+位置专属** | 最精确的配置 | 劫-中路 |
| **英雄通用** | 适用于该英雄所有位置 | 劫-所有位置 |
| **位置通用** | 适用于该位置所有英雄 | 中路-所有英雄 |

### 3. 可视化符文选择器

#### 功能特性

- ✅ **5个符文系**：精密、主宰、巫术、启迪、坚决
- ✅ **自动过滤**：根据主系自动过滤可用副系
- ✅ **符文图标**：显示符文图标和名称
- ✅ **选择验证**：实时验证符文配置
- ✅ **进度提示**：显示已选择 X/9 个符文

#### 使用方法

1. **选择主系**：点击符文系图标
2. **选择主系符文**：
   - 基石符文（选1个）
   - 第一层（选1个）
   - 第二层（选1个）
   - 第三层（选1个）
3. **选择副系**：点击副系符文系图标
4. **选择副系符文**：选择2个符文
5. **选择属性碎片**：
   - 进攻（选1个）
   - 灵活（选1个）
   - 防御（选1个）
6. 完成！自动保存

### 4. 一键导入功能

#### 从 OP.GG 导入

**前提条件**：已选择英雄和位置

**步骤**：
1. 填写英雄和位置
2. 点击"**从 OP.GG 导入**"
3. 系统自动获取最佳推荐符文
4. 查看并调整（可选）
5. 保存

**优点**：
- ✅ 自动获取当前版本最佳符文
- ✅ 基于高段位数据
- ✅ 一键填充，无需手动选择

#### 从游戏客户端导入

**前提条件**：游戏客户端已打开且有符文页

**步骤**：
1. 在游戏客户端配置符文
2. 打开 Nidalee 符文编辑器
3. 点击"**从客户端导入**"
4. 系统读取当前符文页
5. 保存为自定义配置

**优点**：
- ✅ 快速保存当前符文
- ✅ 适合保存特殊配置
- ✅ 一键操作

## 高级用法

### 智能匹配优先级

系统使用 **7级优先级算法** 匹配最佳符文配置：

```
优先级 1: 英雄+位置专属 + 默认标记
         示例: 劫-中路 (默认) ⭐

优先级 2: 英雄+位置专属
         示例: 劫-中路

优先级 3: 位置通用 + 默认标记
         示例: 中路通用 (默认) ⭐

优先级 4: 位置通用
         示例: 中路通用

优先级 5: 英雄通用 + 默认标记
         示例: 劫通用 (默认) ⭐

优先级 6: 英雄通用
         示例: 劫通用

优先级 7: OP.GG 推荐（回退）
         自动调用 OP.GG API
```

### 配置示例

#### 示例 1：劫的多位置配置

```
配置 A: 劫-中路-电刑 (默认)
  作用域: 英雄+位置专属
  优先级: 最高
  使用场景: 选劫+中路时应用

配置 B: 劫-打野-征服者 (默认)
  作用域: 英雄+位置专属
  优先级: 最高
  使用场景: 选劫+打野时应用

配置 C: 劫通用-电刑
  作用域: 英雄通用
  优先级: 较低
  使用场景: 选劫+其他位置时应用（回退）
```

#### 示例 2：位置通用配置

```
配置: 中路通用-奥术彗星 (默认)
  作用域: 位置通用
  优先级: 中等
  使用场景: 选中路+任意法师英雄时应用（如果没有该英雄的专属配置）
```

### 配置导出/导入

#### 导出配置

1. 进入"复杂模式"
2. 点击"**导出配置**"
3. 保存 JSON 文件到本地

#### 导入配置

2. 点击"**导入**"（功能待完善）
3. 选择 JSON 文件

## 常见问题

### Q1: 符文没有自动应用？

**检查清单**：
1. 是否在"设置 > 符文配置"中启用了自动应用？
2. 是否选择了正确的策略？
3. 查看控制台日志，确认是否有错误

### Q2: 如何为不同位置配置不同符文？

为同一个英雄创建多个配置，每个配置选择不同的位置。系统会根据实际位置自动匹配。

### Q3: 如何设置位置通用符文？

1. 新增配置
2. 作用域选择"**位置通用**"
3. 只选择位置，不选择英雄
4. 该位置的所有英雄都会使用此配置（如果没有更精确的配置）

### Q4: 配置数据存储在哪里？

存储位置：`~/.nidalee/store/rune-configs.json`

数据格式：JSON

备份方法：使用"导出配置"功能

### Q5: 如何备份我的符文配置？

1. 进入"复杂模式"
2. 点击"**导出配置**"
3. 保存 JSON 文件到安全位置
4. 如需恢复，使用"导入"功能

### Q6: 符文 ID 从哪里获取？

推荐使用"**从 OP.GG 导入**"或"**从客户端导入**"功能，无需手动查找符文 ID。

如需手动输入，可参考：
- 主宰-电刑：8112
- 精密-征服者：8010
- 巫术-奥术彗星：8229
- 等等...

### Q7: 为什么有些符文无法选择？

副系符文受到主系的限制。每个主系只能搭配特定的副系。系统会自动过滤不可用的副系。

### Q8: 如何查看符文配置的使用次数？

在"复杂模式"的配置列表中，每个配置都会显示"使用 X 次"。每次自动应用时会自动增加计数。
